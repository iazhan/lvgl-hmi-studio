# scripts/ —— 门禁与检查脚本

> 文件名带两位数字前缀，**编号即分组**：`0x` 入口、`1x` 静态守卫、`2x` 门禁读数、`3x` 维护/生成器。
> 新加脚本按"它属于哪一组"取下一个空号，不要按添加顺序续号。

## 0x 入口

| 脚本 | 角色 | 什么时候跑 | 交互 |
|---|---|---|---|
| `00_gate.sh` | **阻断门禁**：脚本语法 → `dotnet build`（警告即失败）→ 全量测试（大队 / 需独占的 git 用例分两段）→ 静态守卫 → 收口工具自检 | 提交前 | 否（可 `TEST_HANG_TIMEOUT=30s` 压低等待） |

一条命令跑完全部；它内部调下面 1x / 2x 组的脚本。本仓库没有接 CI 服务，这就是唯一的门。

## 1x 静态守卫（读源码文字，不跑代码）

| 脚本 | 守什么 | 被谁调 |
|---|---|---|
| `10_check_path_hygiene.sh` | 产品/工具代码不得硬编码开发机家目录（ACII 引号包裹的 `/home/<名字>/`） | `00_gate.sh` |
| `11_check_xaml_duplicate_wiring.py` | 同一个 `.axaml` 里同一事件的重复接线（Avalonia 后接的静默覆盖先接的） | `00_gate.sh` |
| `12_check_dock_bus_only_subscription.py` | 停靠面板只订阅静态总线、不自建事件源 | `00_gate.sh` |
| `13_check_index_based_control_lookup.py` | 列表控件按索引取行，不按显示位置猜 | `00_gate.sh` |
| `14_check_lvgl_userdata_lifetime.py` | LVGL user_data 的生命周期（对象销毁后不得留悬垂引用） | `00_gate.sh` |

四个 `.py` 守卫都支持 `--selftest`（判据两侧自检）与 `--json`（机器可读）。

## 2x 门禁读数（把一跑日志变成可比的数字）

| 脚本 | 角色 |
|---|---|
| `20_gate_run.sh` | 跑一次门禁并把输出落成固定形态的日志（末行是汇总），供 21/22 读取；`--selftest` 自检三档 |
| `21_gate_readings.py` | 从日志里抽出收口表格要用的每个数（步数、用例数、耗时、loadavg）；只读，不判定 |
| `22_gate_diff.py` | 两份日志逐项对比（"这次比上次多了哪些失败 / 慢了多久"）；`--selftest` 四档 |
| `23_face_residual.py` | 视图面残差统计（哪些视图还有未归位的控件属性）；`--top N` / `--selftest` |

## 3x 维护

| 脚本 | 角色 | 什么时候跑 |
|---|---|---|
| `30_sync_localization.py` | 同步 `Lang.cs` 常量与 `Strings.*.json`；默认干跑，`--write` 才落盘 | 新增/改界面文案后 |

## 加新脚本

1. 按组取号（`15_`、`24_`…），文件名 `NN_短名.sh|.py`，小写下划线。
2. 头部注释写清"判什么 / 什么时候跑 / 退出码含义"，不写改动史。
3. 能被 `00_gate.sh` 调的就接进去；不能的在这里补一行表格说明谁在用。
4. `.sh` 要 `chmod +x`（文档守卫会检查 `bash scripts/xxx.sh` 引用的脚本可执行）。
